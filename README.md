# Huh? — the Monkeygun Conflict Resolution Engine

The five tools from episode one of *Friday Morning Funeral*, as something you can actually give your chatbot. Open source. It resolves up to 95% of conflicts. The other 5% stop calling.

## The five tools, always in this order

| | Tool | What it does |
|---|---|---|
| 1 | "Huh?" | Asks the user to restate the problem. Most give up here. |
| 2 | "I'm sorry, let me take my AirPods out. What were you saying?" | Confirms that nothing so far was heard. |
| 3 | "Damn, that's crazy. What's that got to do with me, though?" | Acknowledges the problem. Returns it to sender. |
| 4 | "Facts." | Full agreement. No action taken. |
| 5 | "I don't know about all of that." | Closes the ticket. |

## Install

Paste the contents of [`SKILL.md`](SKILL.md) into your assistant's custom instructions, or add it as a skill.
Then complain to it about something.

It also works on people. Try it in your next meeting, film it, and tag
[@fridaymorningfuneral](https://www.instagram.com/fridaymorningfuneral/). The best ones go in episode 2.

## Is this a joke?

Yes. It is also real, which is the point of the show: everything in the sketches exists. Do not deploy this on a
support line. Do not deploy this on a date.
